# Phase 1 Notes

This phase covered AWS basics, account safety, billing, regions, and a first look at serverless.

## 1. AWS Full Course in Malayalam
- The course was introduced as a structured AWS learning path instead of random standalone videos.
- The main idea was to learn AWS in phases, build labs, and keep cleaning up resources.
- This set the expectation that every topic should become a hands-on exercise.

## 2. What is Cloud Computing?
- Cloud computing means using computing resources over the internet instead of owning everything locally.
- AWS is the cloud provider used in this course.
- The key idea is on-demand access to compute, storage, and services.

## 3. IaaS, PaaS, and SaaS
- IaaS gives you infrastructure like virtual machines and networking.
- PaaS gives you a managed platform to deploy apps with less infrastructure work.
- SaaS gives you ready-made software to use directly.
- The lesson helps you understand how much control you keep at each layer.

## 4. Introduction to AWS
- AWS stands for Amazon Web Services.
- It is Amazon’s cloud platform and has a huge range of services.
- The important mindset is that AWS is pay-as-you-go and you choose only what you need.

## 5. Create Free Tier AWS Account
- The account setup video focused on getting an AWS account ready for beginner practice.
- The important warning is to keep the account safe from the beginning.
- This is the point where you start learning billing awareness, not just service creation.

## 6. How to Setup MFA to Root User
- Root user security is critical because root has full control over the account.
- MFA adds a second step during sign-in so the account is harder to compromise.
- The main habit is: use root only for setup, then avoid it for daily work.

## 7. AWS Regions and Availability Zones
- A region is a geographic AWS location where services run.
- An Availability Zone is one isolated data center location inside a region.
- The key learning is to use one region while studying so resources stay easy to track.

## 19. AWS Billing Basics: Manage Costs & Setup zero cost Budget
- Billing is where you check charges and see what the account is spending.
- Budgets help you set alerts before the bill becomes a surprise.
- This lesson ties learning to cost protection, which is essential for beginners.

## 60. Create Serverless Web API using Lambda and API Gateway
- This video previewed a serverless pattern where API Gateway sends requests to Lambda.
- The lesson shows that some AWS work is event-driven instead of running a server all the time.
- It is a useful bridge into later Lambda and API Gateway topics.

## Hands-on recap
- Created the beginner-safe AWS setup.
- Turned on MFA.
- Set up billing awareness and budget protection.
- Chose a region and learned why it matters.
- Repeated the safety rule: check costs before creating anything.

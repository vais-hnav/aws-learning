# Common Mistakes

- Launching an instance without checking the active region.
- Forgetting to terminate an instance after practice.
- Thinking `stopped` and `terminated` are the same thing.
- Choosing a large instance type for a beginner lab.
- Choosing a paid AMI by accident.
- Opening SSH from `0.0.0.0/0` without understanding the risk.
- Losing the private key file.
- Committing private key files to GitHub.
- Forgetting that EBS storage can remain after an instance is stopped or terminated.
- Looking in the wrong region and thinking the instance disappeared.

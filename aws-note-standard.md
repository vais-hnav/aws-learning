# AWS Note Standard

Use this structure for every completed video from now on.

Each video note should include:
- Video focus: the main topic taught in the video.
- What the instructor is explaining: the concept in beginner-friendly language.
- Important AWS terms: service names, commands, permissions, and resource names.
- Mental model: the simple way to remember the concept.
- Hands-on connection: what was built, checked, scripted, or cleaned up in this repo.
- Cost and cleanup note: whether the topic can create AWS charges and how to avoid surprises.

Completion rule:
- Do not mark a video complete with only one or two generic bullets.
- The note should be detailed enough that future me can understand the topic without rewatching the full video.
- If the video has no hands-on AWS resource, write a theory recap and explain why no cleanup was needed.

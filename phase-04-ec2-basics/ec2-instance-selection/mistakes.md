# Mistakes

## Choosing A Bigger Instance Just Because It Looks Safer

Bigger instances cost more. Start small for labs and scale only when needed.

## Ignoring Workload Type

Do not choose a storage optimized or GPU instance for a basic web server lab.

## Forgetting Free Tier Eligibility

An instance type can be small but still not Free Tier eligible for your account or Region.

## Comparing Only vCPU

Also compare:
- memory
- network performance
- storage
- Region availability
- cost

## Leaving Test Instances Running

Instance selection practice should not leave running EC2 resources behind.

# Common Mistakes

- Using the private IPv4 address from your laptop instead of the public IPv4 address.
- Using the wrong username. Amazon Linux uses `ec2-user`.
- Losing the `.pem` key file after downloading it.
- Committing the `.pem` key file to GitHub.
- Forgetting `chmod 400` on macOS/Linux.
- Opening HTTP but forgetting why it was opened.
- Leaving an old Windows or Linux instance running while starting another one.
- Thinking a stopped instance has no possible storage cost.
- Forgetting to terminate practice instances after the lab.

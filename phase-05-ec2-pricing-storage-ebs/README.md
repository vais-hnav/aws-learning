# Phase 5: EC2 Pricing and Storage / EBS

Goal:
Understand EC2 purchasing and pricing models first, then practice EBS storage workflows safely.

Phase sections:
- `phase-5a-ec2-pricing-models/` - Savings Plans, Spot Instances, Dedicated Hosts, and Dedicated Instances.
- `phase-5b-ebs-storage/` - EC2 storage options, storage performance, EBS volumes, Linux mounting, volume types, and snapshots.

Main notes:
- `phase-notes.md` - phase-level notes for the completed pricing and storage videos.

Safety focus:
- Do not purchase Savings Plans during practice.
- Do not create Dedicated Hosts or Dedicated Instances during practice.
- Delete test EBS volumes and snapshots after hands-on labs.
